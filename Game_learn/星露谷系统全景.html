怎么用这张图（美术视角）
  1. 先看顶部五层：确认"星露谷的支柱/循环"是什么——这是你设计自己游戏时最先要定的。
  2. 再挑一个系统组（如钓鱼），打开对应 JSON，看"这个系统需要记录哪些字段"。
  3. 把字段翻译成 Godot 语言：一张表 = 一个 Resource；一个系统 = 一个 Scene + 若干节点；资产命名约定 = 你的文件夹/文件名规范。
  4. 最后对照蓝图模板，为自己的游戏画出同样的全景图（先定支柱，再列系统，再排依赖）。
