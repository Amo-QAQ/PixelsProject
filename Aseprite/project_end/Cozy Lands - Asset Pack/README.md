## File Naming

Assets follow a consistent naming scheme so you can find files at a glance:

- **Characters/Animals:** `subject_action_direction` → `girl_walk_f.png`, `chicken_idle01_b.png`
- **Other assets:** `name_attribute` → `grass.png`, `grass_shadow.png`, `berry.png`, `house_01.png`

The folder itself tells the asset type (e.g. everything in `Terrain/Tilesets/` is a tileset), so file names stay short and clean.

Directions: `f` = front, `b` = back, `l` = left, `r` = right.
