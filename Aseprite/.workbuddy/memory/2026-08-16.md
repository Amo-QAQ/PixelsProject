## Aseprite 精灵图批量导出方案

### 问题
用户需要按 **切片(Slice) × 标签(Tag)** 批量导出精灵图（Sprite Sheet），Aseprite 内置的 Sprite Sheet 导出不支持按切片裁剪。

### 最终解决方案
**两步走：Aseprite CLI + Python 合成**

1. **Aseprite 命令行导出单帧**（无弹窗、全自动）：
   ```bash
   "D:/Program/Steam/steamapps/common/Aseprite/Aseprite.exe" -b ji.aseprite --split-tags --split-slices --save-as sprite_sheets_export/{tag}{slice}.png
   ```

2. **Python 合成精灵图**（`sprite_sheet_maker.py`）：
   - 自动识别 `标签切片帧号.png` 格式
   - 按前缀分组，横排拼成精灵图
   - 生成 JSON 帧数据

### 关键发现
- Aseprite 安装路径: `D:\Program\Steam\steamapps\common\Aseprite\Aseprite.exe`
- Aseprite 1.3.18.2 版本 API 特点：
  - `app.command.Export` 不存在，用 `SaveFileCopyAs` 或 CLI
  - `spr.tags` 是 userdata 类型，只能用 `ipairs()` 遍历
  - `tag.fromFrame`/`tag.toFrame` 返回 FrameObj 不是数字
  - `Image:free()` 方法不存在
  - 对话框返回值不能用 `result.field` 方式读取

### 输出结果
- 18 张精灵图 (7标签 × 3切片 = 21组，部分标签帧数不足)
- 位置: `D:\CodeProject\PixelsProject\Aseprite\final_sprite_sheets\`
