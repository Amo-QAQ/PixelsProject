# GIF 编辑器 · 使用说明

## 启动
**双击 GIF编辑器.html** 直接用浏览器打开即可，无需任何启动器、不联网、不上传文件，数据全程留在本机。

## 文件
| 文件 | 作用 |
|---|---|
| GIF编辑器.html | 唯一文件，界面 + 拆帧/合成引擎全部内置（gifenc 编码库 + 自研 GIF 解码器，均已内联） |

## 功能
1. **导入素材**：拖入 PNG/JPG/WebP 直接成帧；拖入 `.gif` 自动拆帧并保留原延迟；拖入 `.zip` 自动解压按文件名排序。可多次追加。
2. **调整大小 / 画幅**：改宽高；画幅预设 1:1 / 4:3 / 3:4 / 16:9 / 9:16——**扩边不裁切**（256×122 选 1:1 → 256×256）；填充可选透明或不透明色（色盘 + 编号输入）。
3. **底图逐帧变换**：播放头停哪帧，用「底图 X/Y/缩放%」调该帧的位移缩放，**画布空白处直接拖动底图**；卡片上显示 `x:.. y:.. ×..`；「变换→选中帧」批量复制。
4. **添加文本**：加文字层，可直接在预览画布上拖动，右侧列表改字号/颜色/位置。
5. **添加图片/GIF 贴图**：叠加 PNG 或 **GIF 动图贴图**（带「循环」次数），可拖拽。
   - **逐帧叠加**：每层「全部 / 仅本帧 / 选中帧」+ **起帧/止帧输入框**；有自定义叠加的帧时间线卡片右下角显示橙色 ✦。
6. **帧时间线**：卡片自动换行；缩略图拖拽排序、点选/Shift 多选、每帧延迟单独改；工具栏：复制选中 / **序列×2**（整个 GIF 播两遍）/ **停留N帧**（选中帧复制 N 次=单图出现多帧）/ 删除选中 / 清空。
7. **实时预览**：循环播放，所见即所得；⏮/⏭ 单帧步进。
8. **撤销/重做**：Ctrl+Z / Ctrl+Y，或工具栏按钮；Delete 删除选中帧。
9. **导出**：文件名 + 循环次数，导出为 GIF（透明通道保留），自动下载。

## 已知限制（v1）
- 新追加的帧若比第一张大，画布尺寸以首批帧为准，用「调整大小」手动放大
- 帧图本身不存，刷新页面帧会丢（设置/文本/图片层位置会记忆）
- 文字用系统字体，如需特定像素字体可后续扩展
- zip 内的 .gif 只取第一帧
