## 第三轮优化：朝向修复 + 行为自然化
**朝向问题修复**：
- **根本原因**：切换到 WALK 状态时，先播放动画（用旧朝向），后更新方向
- **修复方案**：
  - 在 `_pick_and_transition_to_new_state()` 中，WALK 状态必须先调用 `_change_direction()` 和 `_update_facing_from_direction()`
  - 在 `SQUAT_UP` 过渡完成后，同样先更新方向再播放行走动画
  - 提取 `_play_walk_anim()` 统一处理行走动画的朝向和翻转
  - 优化 `_apply_flip()` 逻辑：只有方向向右且朝向为 L 时才翻转

**行为自然化调整（走走停停模式）**：
- 权重重新分配（以行为频率为主）：
  - 行走: 20% → **60%**（主要状态）
  - 待机1: 18% → **12%**（短暂停顿）
  - 待机2: 15% → **10%**（短暂停顿）
  - 吃食: 17% → **8%**（偶尔发生）
  - 睡觉: 15% → **5%**（稀有）
  - 蹲下待机: 15% → **5%**（稀有）
- 持续时间大幅调整：
  - 行走: 3-6秒 → **4-8秒**（走更长的距离）
  - 待机1/2: 2-4秒 → **0.5-2秒**（短暂停留）
  - 吃食: 2.5-4.5秒 → **1.5-3秒**
  - 切换概率: 0.003 → **0.004**（约每3-4秒有几率停下）
- 朝向保持机制：
  - 待机状态 80% 概率保持当前朝向（避免频繁转身）
  - 吃食状态 70% 概率保持
  - 只有睡觉和特殊动作才随机朝向

## 第四轮优化：短促节奏 + 防止连续静止
**行为节奏调整（走走停停模式）**：
- 行走时长: 4-8秒 → **1.5-2.5秒**（短促行走）
- 待机/吃食: 0.5-3秒 → **1.0-2.5秒**（短暂停留）
- 切换概率: 0.004 → **0.008**（约每2秒有几率停下）
- 权重重新平衡：
  - 行走: 60% → **45%**
  - 待机1: 12% → **20%**
  - 待机2: 10% → **15%**
  - 吃食: 8% → **12%**
  - 睡觉/蹲下: 各5% → **各4%**

**防连续静止机制**：
- 新增 `consecutive_idle_count` 计数器
- 最多允许连续 **2个静止状态**
- 超过后强制提高行走权重到 **80%**
- 确保不会出现"一口气做很多停止动作"的情况

**目标效果**：
```
走2秒 → 停1.5秒(待机) → 走2秒 → 停2秒(吃食) → 走2秒...
偶尔: 停一下 → 蹲下过渡 → 睡3秒 → 起立 → 继续走
```

## 第五轮优化：8方向移动（星露谷风格）
**移动系统改造**：
- **旧**：4方向直线移动（僵硬）
- **新**：8方向移动 + 4向动画（自然流畅）

**实现细节**：
1. `_change_direction()`:
   - 60% 概率选择基本4方向 (上/下/左/右)
   - 40% 概率选择斜向4方向 (左上/左下/右上/右下)
   - 所有方向向量已归一化，斜向速度一致

2. `_update_facing_from_direction()` (星露谷逻辑):
   ```
   判断主轴：abs(direction.x) > abs(direction.y)?
   ├─ YES → 水平为主
   │   ├─ x > 0 → 右 (facing="L" + flip_h=true)
   │   └─ x < 0 → 左 (facing="L")
   └─ NO → 垂直为主
       ├─ y < 0 → 上/后 (facing="B")
       └─ y > 0 → 下/前 (facing="Z")
   ```

3. 效果：
   - 右上移动 → 面向右或上（取决于哪个分量更大）
   - 移动轨迹更自然，不再只有横平竖直
   - 动画仍然保持4向，不会出现斜向动画

## 第六轮优化：斜向角度调整
**问题**：45度对角线太夸张，看起来诡异
**解决方案**：改为小角度偏移（约25-30°）

**具体调整**：
```gdscript
# 旧：45度对角线
Vector2(1, 1).normalized()  # → 45°

# 新：约30度偏移
Vector2(0.85, 0.53).normalized()  # → ~32°（更接近主轴）
```

**4个新斜向方向**：
- 右上：(0.85, -0.53) → 约32度
- 右下：(0.85, 0.53) → 约32度  
- 左上：(-0.85, -0.53) → 约32度
- 左下：(-0.85, 0.53) → 约32度

**视觉效果**：轻微倾斜，像真实动物走路时的自然偏移，而非刻意走对角线
